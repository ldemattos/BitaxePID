# homeassistant

## Task: Create a new homeassistant

### Requisites:
- Create a new home assistant integration plugin that must read all the outputs from start_metrics_server() function;
- Directives:
	- The new files must be store in the ./homeassistant folder;
	- The header plugin header must have the instruction to use the plugin;
	- It must be possible to disable reading of any of available variables;
	- The bitaxe ip address must be adjustable;
	- The bitaxe port address must be adjustable;
	- The sampling time (in seconds must be adjustable);
